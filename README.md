# 《英文量化社区经验汇编》

本书把 Elite Trader、Wilmott、Quant StackExchange、Reddit、Hacker News、QuantConnect、Numerai、X 等英文量化社区二十余年的讨论，整理成一部可检索、可核对的中文专题书。它基于 343 篇精读帖子（2002–2026），按 Alpha、回测与实盘、执行与风控、期权与波动率、期货与市场结构、工程与交易心理六个部分展开；社区观点均附来源，书中数字来自帖子自述，不构成投资建议。
