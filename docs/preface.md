# 序言

## 为什么写这本书

英文的量化社区——Elite Trader、Wilmott、Quant StackExchange、Reddit 的 r/algotrading 与 r/options、Hacker News、QuantConnect 论坛——积累了二十多年的讨论。这些讨论里有大量一手的失败教训、数字与分歧，但它们分散、冗长、夹杂着噪声，并且是英文。

本书的读者是一位**已经具备量化与期权基础、在做 0DTE 期权回测与实盘，同时涉及期货与股票**的交易者。因此，书的取舍标准是：**对执行、风控、回测、期权这四件事有用的从业者经验优先**；与此无关的（纯数学、书单、职业八卦、GME/WSB 梗图、平台使用说明）已在精读阶段被跳过，原因逐条记录在来源表里（见附录 C）。

## 本书的写法

1. **概念由本书作者讲解**：用 LaTeX 写出必要的公式（如 Kelly、IC 的 t 值、gamma/theta 随到期时间的标度）。这些解释是通用金融知识，**不归属于任何帖子**。
2. **社区观点用中文转述**，每一条都附有来源链接（标题、站点、日期）。转述力求忠实：只写我读到的内容；读不到的（被截断的帖子、仅有列表页的 QuantNet 帖子）会明确说明“仅依据早先摘要”。
3. **分歧单独列出**：每章都有一节以表格形式列出阵营分歧。
4. **数字的处理**：凡是自述的业绩数字，一律标注“（作者自述）”，并在可能时做自洽性检验（例如用 $\text{PF}=\frac{pW}{(1-p)L}$ 交叉验证胜率、盈亏比与总收益是否相容）；**自洽并不等于正确**。
5. **每章的结构**：本章要点 → 概念 → 社区观点（含案例与数字）→ 分歧 → 小结 → 自查清单。

## 如何阅读

- 全书约 20 章，分六个部分。若时间有限，请读第 7–13 章。
- 来源链接指向原帖，建议在引用或据此做决策前**回到原帖**核对上下文。
- 术语表（附录 A）给出了中英对照。

## 限制与诚实声明

!!! warning "请务必阅读"
    **1. 样本不是随机的。**帖子来自搜索与热门列表，偏向“有讨论的话题”。沉默的大多数、已经退出的交易者、不上论坛的机构，都不在样本里。
    
    **2. 几乎所有业绩都是自述。**我们没有核实任何一个账户、对账单或回测代码。
    
    **3. 站点覆盖不均。**Reddit 只有 RSS 摘录（帖子与部分高赞评论的前几百字），没有点赞数；Elite Trader 与 Wilmott 是抽样页；X 的搜索在 2026 年被广告与机器人淹没，只保留了少数有实质内容的帖子；QuantNet 通过浏览器读取，多为 2008–2013 年的问答，与交易场景的相关性较弱，其中不少帖子只有列表页与简短摘要。
    
    **4. 无法访问的站点。**Nuclear Phynance（似乎已下线）、Lobsters 搜索（被 Anubis 拦截）、Quantocracy 订阅源（500 错误）无法读取；Kaggle 论坛未尝试；部分子版块因限流被跳过。
    
    **5. 时间。**跨度从 2002 年到 2026 年；早期（2000 年代）的内容反映的是当时的市场结构与券商生态，不能直接外推到今天。
    
    **6. 这不是投资建议。**书中任何策略、参数或数字都不构成建议。
