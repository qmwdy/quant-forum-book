# 量化交易社区经验录

**一本写给 0DTE 期权与期货交易者的中文专题书**

本书把英文量化社区二十多年的讨论，整理成一部可检索、可核对、可反驳的中文读物。它基于 **343 篇精读的帖子**（Elite Trader、Wilmott、Quant StackExchange、Reddit、Hacker News、QuantConnect、Numerai、QuantNet、X 等，日期跨度 2002–2026），而不是基于某个人的观点或二手总结。

!!! abstract "这本书是什么"
    - 一部**“社区经验的转述与分歧地图”**：每章先讲概念（含公式），再摘述来源帖子里的观点，再列出阵营分歧，最后给出小结与自查清单。
    - 每一个来自社区的观点都带有可点击的来源（标题、站点、日期）。凡是本书作者自己的解释或计算，都明确标注为“本书作者”。
    - 数字一律是**帖子里的自述**，除非书中注明做过自洽性检验；没有一个数字是由我们发明的。

!!! warning "这本书不是什么"
    - 不是投资建议，也不是对任何策略盈利性的背书。
    - 不是对论坛“真相”的裁决：论坛上的业绩与说法，大多无法核实，并且存在严重的幸存者偏差。

## 如何阅读

- 想快速抓重点：每章开头的“本章要点”与结尾的“小结/自查清单”。
- 想直接用于 0DTE 实盘：先读 **第 7–9 章（执行、风控、爆仓案例）** 与 **第 10–13 章（波动率、卖权、0DTE、业绩判读）**。
- 想核对来源：[附录 B 来源索引](appendix/index-by-chapter.md)（按章节）、[附录 B2](appendix/index-by-site.md)（按站点）；方法与覆盖限制见 [附录 C](appendix/method.md)。
- 术语不熟：[附录 A 术语表](appendix/glossary.md)。

## 一句话总结全书

> 社区二十年的经验，几乎都落在同一个结论上：**把成本算够，把仓位压小，把最坏的一天想清楚，再谈 edge。**
